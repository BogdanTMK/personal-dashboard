## 1. Актуальность темы

Данный проект направлен на помощь с организацией личного рабочего пространства студента через единный информационный дашборд.

Приложение направлено на помощь с отслеживонием учебных задач и является местом для быстрого доступа к полезным ссылкам(записи лекций, информационные ресурсы, презентации). 

Актуальность работы заключается в создании полноценного Fullstack-приложения, которое объединит:
- быстрый доступ к сайту с расписанием
- менеджер учебных задач
- хранилище полезных ссылок на лекции

Проект также служит практической базой для изучения взаимодействия клиентской части, серверного API и базы данных.

## 3. Предполагаемые функциональные возможности

**1. Быстрый доступ к расписанию** 
В шапке находится ссылка на mstimetable, перенаправляющее на актуальная расписание для моей группы.
**2. Список учебных задач** 
Добавление задачи (название, дедлайн). Отметка о выполнении. Удаление задачи.
**3. Хранилище ссылок** 
Добавление ссылки (название + URL + категория + заметка(опционально)). Открытие по клику. Удаление.
**4. Серверное хранение данных** 
PostgreSQL на сервере. Данные не теряются при смене устройства.
**5. Две основные страницы** 
Главная (задачи) + страница ссылок. Навигация через шапку.
**6. API-взаимодействие** 
Frontend отправляет запросы на сервер, сервер работает с базой данных
